# 📌 ESP32 BLE Media Keyboard

Программируемая Bluetooth-клавиатура на базе **ESP32**, работающая в режиме **BLE HID** и предназначенная для управления мультимедийными функциями компьютера или мобильных устройств.  
Поддерживает **8 физических кнопок**, гибко настраиваемых через **Bluetooth** с сохранением конфигурации в **EEPROM**.

ESP32 Macro Manager — это клиент-серверное приложение для настройки, управления и хранения макросов сохраненных макросов, предназначенное для работы с BLE Media Keyboard. - https://github.com/danikbuda/ESP32_Settings_programs.git
---

## 🔎 Описание проекта

Проект реализует BLE HID-устройство, которое определяется системой как **мультимедийная клавиатура**.  
Назначение клавиш может быть изменено **без перепрошивки** — через передачу JSON-конфигурации по Bluetooth Classic.

Устройство поддерживает несколько режимов работы, включая **рабочий режим**, **режим конфигурации** и **глубокий сон (Deep Sleep)** для экономии энергии.

## 🧠 Режимы работы

Режим выбирается при запуске ESP32 в зависимости от состояния управляющих кнопок.

### 🔹 Рабочий режим
- ESP32 работает как BLE-клавиатура
- Отправляет медиа-команды при нажатии кнопок
- Поддержка стандартных HID Media Keys

### 🔹 Режим конфигурации
- Устройство определяется как `ESP32_BT_JSON`
- Принимает JSON-конфигурацию по Bluetooth
- Сохраняет настройки в EEPROM

### 🔹 Режим сна (Deep Sleep)
- Минимальное энергопотребление
- Предназначен для автономных и батарейных устройств

| Button 7 | 12 |

- Активный уровень — `LOW`

## 🎹 Поддерживаемые медиа-клавиши

Проект поддерживает стандартные BLE HID Media Keys:

- `KEY_MEDIA_PLAY_PAUSE`
- `KEY_MEDIA_NEXT_TRACK`
- `KEY_MEDIA_PREVIOUS_TRACK`
- `KEY_MEDIA_STOP`
- `KEY_MEDIA_MUTE`
- `KEY_MEDIA_VOLUME_UP`
- `KEY_MEDIA_VOLUME_DOWN`
- `KEY_MEDIA_CALCULATOR`
- `KEY_MEDIA_WWW_SEARCH`
- `KEY_MEDIA_WWW_STOP`
- `KEY_MEDIA_WWW_BACK`
- `KEY_MEDIA_CONSUMER_CONTROL_CONFIGURATION`
